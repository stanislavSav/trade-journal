## How to pick up a task

1. Read its **Context to load**, the plan sections in **Spec refs**, and the previous **Hand-off log**.
2. Set the task to `In progress` here and in the file. Do the work; tick the acceptance criteria.
3. Before you stop, append a dated entry to the **Hand-off log**. When every criterion holds, set `Done` in both places.

**In:**

- A parking-lot file for anything the owner must decide.

  catalogue.md (and `catalogue.ts`) where a brand changed.

  online, before you start tagging" (plan §10.4).

**Out:** new features. Anything found that is not a bug goes to the parking lot or plan §11.
